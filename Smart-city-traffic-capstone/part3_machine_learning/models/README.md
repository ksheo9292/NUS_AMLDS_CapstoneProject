# Models folder

This folder is created and updated when `python basic_train.py` is run.

- `classification_results.csv` contains classification metrics.
- `regression_results.csv` contains regression metrics.
- `cluster_summary.csv` explains the four K-means groups.
- `association_rules.csv` contains rules ranked by lift.
- Files ending in `.joblib` are saved trained models.
- `project_information.json` records the feature list and train-test sizes.
